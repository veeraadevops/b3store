# How to Add Product Images 🥒

## What You Need:
3 pickle images for:
- `classic-pickle` 
- `spicy-pickle`
- `sweet-pickle`

## Image Requirements:
- **Format**: PNG or JPG
- **Size**: At least 300x300 pixels (square works best)
- **Background**: Transparent PNG preferred, or white background

## Where to Get Images:

### Option 1: Free Stock Images
- **Unsplash**: https://unsplash.com/s/photos/pickle
- **Pexels**: https://www.pexels.com/search/pickle/
- **Pixabay**: https://pixabay.com/images/search/pickle/

### Option 2: AI-Generated
- **DALL-E**: Generate custom pickle images
- **Midjourney**: Create stylized pickle illustrations

### Option 3: Icon Sets
- **Flaticon**: https://www.flaticon.com/search?word=pickle
- **Icons8**: https://icons8.com/icons/set/pickle

## How to Add Images in Xcode:

1. **Open Xcode** (already open)
2. In the Project Navigator, go to: **PickleStore → PickleStore → Assets.xcassets**
3. Right-click in the assets area → **"New Image Set"**
4. Rename the image set to one of these exact names:
   - `classic-pickle`
   - `spicy-pickle`
   - `sweet-pickle`
5. Drag your image file into the **"Universal"** slot
6. Repeat for all 3 products
